# Anchor

**A distributed ledger for portable identity.**

The decentralized state layer behind **Ferna ID**, purpose-built for identity.

It provides a shared, consensus-backed source of truth without putting that
state under the control of a single service.

Not a general-purpose blockchain or cryptocurrency.

## → Development

```sh
brew bundle          # Install tooling.
just devnet init     # Generate devnet config.
docker compose up -d # Start CometBFT.
mprocs               # Start the nodes.
```
